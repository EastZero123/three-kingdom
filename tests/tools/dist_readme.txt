삼국지 원정 로그라이트 {VERSION}
====================================

■ 실행
  samgukji.exe 를 실행합니다. 설치는 필요 없습니다.
  samgukji.pck 는 게임 데이터입니다. 반드시 samgukji.exe 와 같은 폴더에 두세요.

■ "Windows의 PC 보호" 경고가 뜰 때
  아직 코드 서명을 하지 않은 프로그램이라 처음 실행할 때 경고가 뜰 수 있습니다.
  [추가 정보] → [실행]을 누르면 실행됩니다.

■ 기록 저장 위치
  %APPDATA%\Godot\app_userdata\삼국지 원정 로그라이트\
  게임 파일을 지우거나 옮겨도 기록은 남습니다.
